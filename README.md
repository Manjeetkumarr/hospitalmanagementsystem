## 🏥 Hospital Management System

A desktop-based Hospital Management System developed using Java Swing and MySQL.

This system manages multiple hospital entities including:
- Patients
- Doctors
- Departments
- Wards & Rooms

It supports full CRUD operations along with admit and discharge tracking and automatic calculation of patient stay duration.

## 🚀 Features

- 👤 Patient Management (Add, Update, Search, Delete)
- 🧑‍⚕️ Doctor Management
- 🏢 Department Management
- 🛏️ Ward & Room Allocation
- 📅 Admit & Discharge Date Tracking
- ⏱️ Automatic Period Calculation (Stay Duration)
- 🔍 Search Functionality
- 💾 MySQL Database Integration

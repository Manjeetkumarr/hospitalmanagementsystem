🏥 Hospital Management System

Java Swing + MySQL Project

📌 Project Description

This project is a Hospital Management System developed using Java Swing and MySQL. It manages patients, doctors, departments, and wards with full CRUD operations.

🚀 Features

  • Patient Management (Insert, Update, Search, Delete)
  • Doctor & Department Management
  • Ward & Room Allocation
  • Admit & Discharge Date Tracking
  • Automatic Period Calculation

🛠️ Technologies Used

  • Java (Swing)
  • MySQL
  • JDBC
